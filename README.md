# Marcelo Vignola agent resources

Public, source-free guidance for AI agents that need to understand Marcelo Vignola's portfolio and navigate its published pages.

## Install the site guide skill

```sh
npx skills add srbunnie/marcelovignola-agent-resources --skill marcelo-vignola-site
```

The skill covers public portfolio discovery and read-only browser tools. It does not provide private source code, API credentials, a remote MCP server, or a way to submit contact forms.
